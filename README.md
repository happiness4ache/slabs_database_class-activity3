SOFTWARE & OPERATING SYSTEMS ANALYSIS

1)VERTICAL VS HORIZONTAL SOFTWARE
VERTICAL SOFTWARE
-vertical software is designed for specific industry or a type of business, for example hospital management software helps hospitals manage patients, medical records and appointments.

HORIZONTAL SOFTWARE
-horizontal software it is used by different types of companies or businesses, for example microsoft excel helps businesses with calculations, budgeting and analysing data.

THE DIFFERENCE BETWEEN THE TWO
-Vertical software serves a specific industry while horizontal software can be used across many industries.


2)OPERATING SYSTEM MODES
BATCH PROCESSING
-batch processing collects and processes data in groups instead of just handling each transaction immediately, for example maybe a company can use batch processing to calculate their employees' monthly salaries at the end of the month.

REAL-TIME PROCESSING
-real-time procesing handles data immediately when an event occurs or show up for example a bank uses real-time processing to update their customer's account balance after a every transaction.

THE DIFFERENCE BETWEEN THE TWO
-batch processing handles data in groups while real-time processing do process data immediately or within a required time.
